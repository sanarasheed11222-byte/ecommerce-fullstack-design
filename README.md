# LuxeMart - Luxury E-Commerce Store

A full-stack e-commerce website built with Next.js, MongoDB, and deployed on Vercel.

## 🌐 Live Site
https://ecommerce-fullstack-design-5atl.vercel.app

## ✨ Features
- 40 products with real images
- User authentication (signup/login)
- Shopping cart
- Checkout with COD and Card payment
- Admin panel to manage products
- Search and filter by category
- Responsive design

## 🛠️ Tech Stack
- **Frontend:** Next.js 15, TypeScript, Tailwind CSS
- **Backend:** Next.js API Routes
- **Database:** MongoDB Atlas
- **Auth:** JWT + bcrypt
- **Images:** Unsplash API
- **Deployment:** Vercel

## 🚀 Setup
1. Clone the repo
2. Run `npm install`
3. Add `.env.local` with your MongoDB URI
4. Run `npm run dev`
